# 💻 1. FRONTEND PART (React.js + Vite)

Yahan aapka poora **User Interface (UI)** aur website ka design hai.

---

## 📂 Key Files & What They Do:

| File / Folder | Purpose |
|---|---|
| **`src/components/Navbar/`** | Top header with logo, animated **`PORTFOLIO`** badge, and section navigation pills |
| **`src/components/Hero/`** | Banner section with typewriter effect, portfolio identity, and contact chips |
| **`src/components/About/`** | Bio, B.Tech CSE (8.01 GPA) details, and key strengths |
| **`src/components/Experience/`** | CodeAlpha internship timeline |
| **`src/components/Projects/`** | Featured projects (AI Resume Builder, EMS Portal, Image Gallery) |
| **`src/components/Skills/`** | Filterable tech stack with brand icons & live counters |
| **`src/components/Education/`** | Degree card & 4 certifications (DUCAT, Outskill, Be 10X, Excel) |
| **`src/components/Contact/`** | Interactive contact message form & direct info cards |
| **`src/components/Footer/`** | Bottom social links and copyright |
| **`src/services/api.js`** | Axios client to talk to the Backend API |
| **`src/styles/`** | Design tokens, color gradients, and glowing animations |
| **`src/App.jsx`** | Main assembly file where all components connect |

```bash
npm install
npm run dev
```
